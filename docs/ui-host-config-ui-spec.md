# 主机配置 UI 规范（可落地到代码 / 墨刀）

目标：保持 Cursor 风格“暗色磨砂 + 高密度管理工具”的一致性，并确保 **最小改动、可复用、可回滚**。

---

## 1. 布局（Layout）

- **整体**：左侧导航/列表（可拖拽宽度） + 右侧工作区（Header + Body）。
- **主机配置页（右侧详情）**：
  - 顶部：**详情 Header**
    - 左：主机名（Title）+ 收藏徽标（Badge，可选）
    - 下：`user@address:port`（Sub）
    - 右：动作条（Actions，自动换行）
  - 中部：字段区（Key/Value Rows）
    - 统一 label 宽度，value 可换行
    - 标签使用 Badge 列表展示（wrap）
  - 空状态：提示 + **主 CTA（新增主机）**

- **主机配置页（左侧列表）**：
  - 顶部：标题 + “+”动作（菜单：新增主机/分组/标签/导入/导出）
  - 搜索：单行输入框（支持清空）
  - 收藏：显示前 N=10（可后续增加“查看全部”）
  - 分组：两级树（组头显示主机数 Badge；空分组显示“暂无主机”占位）
  - 最近连接：按 `lastConnectedAt` 倒序（N=10）

---

## 2. 设计 Tokens（直接对应 `frontend/src/ui/tokens.css`）

你当前已有 tokens，可直接用下列映射作为“墨刀标注”和“代码约束”：

- **背景**
  - 页面背景：`--ds-bg`
  - 面板 1：`--ds-surface-1`
  - 面板 2：`--ds-surface-2`
- **边框**：`--ds-border`
- **文本**
  - 主文本：`--ds-text`
  - 次文本：`--ds-text-muted`
  - 更弱的提示文本：`--ds-text-muted-2`
- **强调色**：`--ds-accent` / `--ds-accent-bg`
- **危险色**：`--ds-danger`
- **圆角**
  - 小：`--ds-radius-sm`
  - 中：`--ds-radius-md`
  - 大：`--ds-radius-lg`
- **间距**
  - `--ds-space-1..5`（4/8/12/16/20）
- **字号**
  - 11/12/14：`--ds-font-11/12/14`
- **焦点态（可用性底线）**
  - ring：`--ds-focus-ring`
  - border：`--ds-focus-border`

## 3. 组件规范（与 `frontend/src/ui/*` 对齐）

- **Button**
  - Primary：关键路径（新增/保存/编辑）
  - Default：一般动作（复制/标记连接/取消收藏）
  - Danger：删除（必须二次确认）
  - 规则：动作条允许换行；移动端优先收敛为“更多菜单”
- **Input / Select**
  - 高度 34px；focus 必须可见（ring + border）
  - 搜索框支持：清空、快捷键（后续可加 Ctrl/Cmd+K）
- **Badge**
  - 用于：收藏、标签、统计数（分组数量等）
  - 规则：wrap 显示，不截断信息
- **Card**
  - 用于：列表分组卡、右侧详情卡、空状态容器

---

## 4. 交互与可用性（建议作为验收点）

- **一致性**
  - 左侧选中态必须与右侧详情强一致（`activeHostId`）
  - 搜索态：建议自动选中第一条结果（减少右侧空白）
- **可扫描性（高频）**
  - 列表项副标题统一显示 `address:port`（必要时 `user@address:port`）
  - 分组头部显示计数 Badge（组内可见主机数量）
  - 空分组也可见（避免“分组被消失”造成困惑）
- **可回滚/低风险**
  - 删除主机：软删除（`deletedAt`），仅影响本地配置；需要 confirm
  - 导入/导出：默认 JSON，导入前预览统计
- **键盘**
  - Esc：关闭弹窗/清空搜索（后续增强）

## 5. 墨刀落地建议（最快可复用做法）

如果你继续用“截图铺底”方式：

- 锁定底图（避免误拖）
- 按本规范重画 **详情 Header / Actions / Badge / 列表分组卡**（这些是复用件）
- 用“链接区域/热区”把：
  - 左侧“+” → 新增主机弹窗
  - 列表项 → 详情页状态
  - 更多（⋯）→ 弹出菜单

## 6. 浏览器验收清单（按这个点一遍就能发现大多数 BUG）

> 建议用 Chrome，打开 `http://127.0.0.1:5173`，进入【主机配置】。

### 6.1 列表与搜索

- **搜索命中**：输入主机名/IP/user/分组名/标签名之一，左侧应只显示【搜索结果】区块，计数正确。
- **搜索无结果**：输入一个不存在的词，应显示“无搜索结果”，并可一键清空搜索。
- **清空搜索**：清空后应恢复收藏/分组/最近区块。
- **选中态**：点击任意主机，左侧高亮与右侧详情一致。

### 6.2 分组与菜单

- **空分组可见**：分组下没有主机时仍显示分组卡，并显示“暂无主机”占位。
- **分组计数**：分组头部 Badge 显示数量（父组=自身+子组总和；子组=自身）。
- **更多菜单**：点分组右侧 ⋯ 打开菜单，再点击空白处应关闭；Esc 应关闭。
- **重命名**：菜单→重命名，输入新名字后应即时生效。
- **删除分组（默认移出）**：删除后分组消失，组内主机应回到“未分组”。

### 6.3 右侧详情与动作

- **详情关闭**：右侧详情点击 “×”，应回到空状态；切换到聊天/再回来仍应为空状态。
- **复制地址**：复制后按钮应短暂提示“已复制”（或弹 prompt 兜底）。
- **标记为已连接**：点击后“最近连接”应出现该主机（按时间倒序）。
- **删除主机**：confirm 后主机从列表消失（软删除）；刷新后仍不应出现。

### 6.4 新增/编辑弹窗

- **校验**：空 name/address、非法端口应提示错误并阻止保存。
- **保存**：保存后左侧应出现该主机并默认选中。
- **分组预选**：从分组菜单“在该分组新增主机”打开编辑器，应自动预选该分组。

### 6.5 导入/导出

- **导出**：导出文件应包含 version/hosts/groups/tags/credentials。
- **导入**：选择合法文件应出现预览统计；确认导入后数据合并且 ID 不冲突。
