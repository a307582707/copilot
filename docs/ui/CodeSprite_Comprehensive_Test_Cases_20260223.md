# CodeSprite 核心功能全面测试清单（78项）

## 模块 1：认证与权限（P0 - 基础门槛）
| 测试点 | 验证路径 |
|---|---|
| 手机号注册 | `/auth/register` → 输入手机号 → 拼图验证 → 收短信 → 设密码 → 注册成功跳转 |
| 邮箱登录 | `/auth/login` → 输入邮箱+密码 → 登录成功跳转到 `/app` |
| 手机号登录 | 同上，用手机号 |
| 登出 | 用户菜单 → 退出 → 回到首页，cookie 清除 |
| 未登录拦截 | 直接访问 `/app` → 弹出登录提示模态框 |
| 管理员登录 | `/admin/login` → 管理员凭据 → 进入后台 |
| 权限隔离 | 普通用户访问 `/admin` → 被拦截 |
| 🌟 **Token 兜底** | 篡改 localStorage 或等 Token 过期 → 点击功能 → 优雅拦截提示“登录过期”并跳回原页 |

## 模块 2：聊天功能（P0 - 核心功能）
| 测试点 | 验证路径 |
|---|---|
| 新建会话 | 点击 `+` → 新会话出现在列表 → 显示欢迎消息 |
| 发送消息 | 输入文字 → 点"发送" → 流式返回 AI 回复 |
| 模型切换 | 下拉选择不同模型 → 发送消息 → 验证模型生效 |
| 图片附件 | 粘贴/上传图片 → 发送 → 消息中显示图片 |
| 会话切换 | 左侧点击不同会话 → 右侧消息列表切换 |
| 关闭会话 | 会话右侧 `⋯` → 关闭会话 → 从列表消失 |
| 删除会话 | 会话右侧 `⋯` → 删除会话 → 永久删除 |
| 清空聊天 | 右键菜单 → 清空聊天 → 确认对话框 → 消息清空 |
| 会话持久化 | 发消息 → 刷新页面 → 会话和消息仍在 |
| 后端状态指示 | 右上角状态圆点：绿=已连接 / 红=断开，点击可配置后端地址 |
| 空会话防重复 | 当前会话为空时再点 `+` → 不创建新会话，聚焦输入框 |
| 🌟 **超长附件攻击** | 粘贴数万行日志代码/超大文本 → 点击发送 → 验证系统拦截 `413 Payload Too Large`，防崩溃 |
| 🌟 **弱网断连阻断** | 在 AI 流式打字时断网 → 敏锐捕获异常，抛出“网络断开”提示 → 恢复后正常 |

| AI Ask 模式 | 切换 Ask → 发送问题 → AI 只回答不执行 |
| AI Agent 模式 | 切换 Agent → 发送指令 → AI 可执行命令 |

| AI Debug 模式 | 切换 Debug → 触发调试流程 |

| 断开连接 | 断开主机 → 状态更新 → 提示重新连接 |

| 插件 flyout | 点 🔌 图标 → 显示"即将推出" |
| flyout 关闭 | ESC / 点击遮罩 → flyout 关闭 |
| 用户规则 | 点"用户规则" → 编辑 → 保存 → 验证生效 |
| 🌟 **伪终端防超时** | 在终端输入阻塞命令 (`top`, `sleep 100`) → 预期触发拦截与提示，防止 SSH 连接池打满 |
| 🌟 **极端 UI 遮罩** | 多指连弹各个抽屉面板然后按 `ESC` → 验证全屏遮罩 `wsNavFlyoutOverlay` 能彻底回收 |
