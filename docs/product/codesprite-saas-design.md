# 码灵（CodeSprite）商业官网 + 账号 + 计费 + 后台（MVP 设计稿）

> 目标：`codesprite.example.com` 作为商业官网入口。用户可注册登录、免费试用、充值（微信/支付宝扫码）、按月收费；登录后可使用网页版（/app）并下载客户端；提供后台管理统计与审计。

---

## 1. 域名与路由建议（统一一个域名，便于证书与回调）

- 官网/控制台域名：`codesprite.example.com`
- API：同域名 `/api/*`（Nginx 反向代理到后端）
- 下载资源：可先同域名 `/downloads/*`（后续可迁移 OSS/CDN）

路由划分（前端 SPA）：

- **公开区**
  - `/`：官网首页（商业化）
  - `/pricing`：价格/计费说明
  - `/download`：下载页（展示版本号/校验值；Windows 优先，Mac 预留）
  - `/docs/*`：使用手册
- **账号**
  - `/auth/register`：注册
  - `/auth/login`：登录
- **产品**
  - `/app`：网页版使用入口（登录后访问）
- **用户中心（个人主页位置建议）**
  - `/me`：个人中心概览
  - `/me/billing`：充值记录 + 消费记录
  - `/me/subscription`：订阅状态/到期/续费
  - `/me/devices`：设备与登录态管理
  - `/me/profile`：账号资料
- **后台**
  - `/admin`：统计总览
  - `/admin/users`：用户列表/详情
  - `/admin/orders`：充值订单
  - `/admin/ledger`：消费流水

## 2. 计费模型（推荐：充值余额 + 按月扣费）

为什么推荐这个模式：
- 更贴合“充值记录 + 后期按月收费”的需求
- 便于财务对账：充值（入账）与扣费（出账）分离

核心对象：
- **Plan**：计费计划（试用/个人月付/企业版）
- **Subscription**：订阅（有效期、状态、下次扣费时间）
- **RechargeOrder**：充值订单（微信/支付宝、金额、状态、二维码/回调信息）
- **Ledger**：消费流水（每月扣费/退款/人工调整）
- **Wallet**：余额（可选，若不做余额也可直接“按月订单扣费”）

关键状态机（简化）：
- RechargeOrder：`created -> qr_issued -> paid -> credited -> closed/failed`
- Subscription：`trialing -> active -> past_due -> canceled/expired`

## 3. 支付对接策略（两阶段）

### 3.1 MVP（可演示，可上线但需人工对账）
- 充值页展示固定收款码（微信/支付宝），用户提交“金额 + 备注/订单号 + 截图”
- 管理后台人工审核通过后入账（写入 RechargeOrder + Ledger）

### 3.2 正式版（自动化，推荐）
- **支付宝当面付**（生成订单二维码）
- **微信 Native 支付**（生成订单二维码）
- 支付成功由平台回调到 `https://codesprite.example.com/api/pay/notify/*`
- 后端验签、落库、入账；前端轮询/WS 更新订单状态

前置条件（待确认）：
- 是否已有微信/支付宝商户号与应用配置（AppId/MchId/证书/密钥）
- 是否需要开票/企业付款/分账等能力（会影响接口设计）

## 4. 后台管理（最小可行）

统计指标：
- 用户：总数、新增、活跃、试用到期数
- 收入：充值金额、扣费金额、退款金额

能力：
- 用户列表/详情（脱敏展示）
- 充值订单查询、状态、回调信息
- 消费流水查询（按月）
- 导出（CSV）与审计日志

权限：
- `user` / `admin` 两级先够用，后续扩展 RBAC
